# ICY TECH capability audit — November 10, 2026

## Method

Fresh bounded discovery of named development roots and GitHub repository visibility;
authoritative version comparison, critical source inspection, focused safe tests and
retained receipts. Not a full security assessment, exhaustive disk inventory or a
fresh full-suite execution for every candidate. No feature-count/LOC scoring.

The public ranked matrix is maintained in `src/data/tech-projects.ts` and rendered at
`/evidence/`; it includes version boundaries, rationale, technologies, implemented
behavior, evidence, limitations and demonstration status. Machine-specific source
paths and full private audit notes stay in ignored validation output.

## Selection

1. Visual Lab AI + independent Standard edition: editable creative computation.
2. Discovery Lab: reproducibility and bounded experimental workers.
3. ICY ALL / Control: process ownership and explicit control-plane boundaries.
4. Photogression: real depth integration and original-photo preservation.
5. Clip Factory: meaningful encoding pipeline and historical real private uploads.
6. Music Branch Resolver: uncertainty-aware retrieval and human review.
7. Fabric / Mind: privacy projections, event infrastructure and recovery.
8. ORIENT: native/offline scientific computation with device limits.
9. Speech Android: native media/DSP bridge and explicit summary consent.
10. Inquiry Engine: bounded retrieval, reviewed save and recovery.
11. FIELDWORK: multimodal integration with known SQL hardening gap.
12. Interface Atlas: synthetic provenance and validation modeling.

This is editorial ordering, not a numerical measurement of developer ability.
Visual Lab editions are compared separately but presented as one flagship family.
Discovery Convergence variants are not counted as unrelated achievements.

Movement Lab additionally has 24 freshly passing pure tests and a clean November 4
revision. Its kinematic model is substantive; dynamic physics, body tracking and
clinical accuracy are not established. ThreeJS Lab has five experiment sources and
fresh syntax checks but no unit-test script; its auto-install launcher was not run.
ICY Reality has a functioning recorded-input observation/instrument/evidence loop,
with historical desktop/touch-emulated receipts, not causal physical discovery.
Its static adapter still references an older Visual Lab engine; no live model or
physical-phone acceptance was established. Installer versions require stronger
current execution evidence before flagship placement. THE ONE STUDIO and a
separately authoritative newer Clip Uploader were not located in bounded discovery.

## Demonstrations and privacy

Only reviewed Visual Lab synthetic renders and a cropped synthetic Clip browser
artifact are newly published. The Clip crop excludes operational automation paths.
The scene-construction and music-review interactions are new explanatory models,
clearly labeled; they are not original-app runtime demos. The ecosystem explorer
is a hand-authored thematic allowlist, not a private registry export.

No private repository was made public and no local service was exposed. Existing
audited PDF resumes are copied byte-for-byte. Private evidence, full raw screenshots,
catalog data, recording IDs, prompts, filesystem paths and credentials are excluded.

retained as full route aliases, not abandoned resume destinations.

## Acceptance boundary

Astro build is a build, not a complete static type check. The new catalog receives a
focused strict TypeScript check and Node tests. Browser checks cover route HTTP,
images/alt text, overflow, visible navigation, internal resources/fragments, synthetic
interaction behavior and PDF hashes. They do not establish WCAG conformance,
screen-reader acceptance or physical-device behavior. Historical receipts remain
historical even when their case study is freshly rendered.
