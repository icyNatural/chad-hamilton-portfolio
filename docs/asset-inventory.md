## Publication policy

- **Portfolio-ready** means the pixels visibly support a verified project claim; it does not mean the file is already copied into the portfolio.
- **Support/process** material may document implementation but should not be a hero image.
- **Generated/internal** material must be disclosed and must never stand in for shipped UI or measured results.
- **Ambiguous** files remain ambiguous until repository/source evidence establishes ownership and project identity.
- Starter logos, generic favicons, build dialogs, errors, unrelated references, and personal/source photos are excluded from the proposed public presentation.
